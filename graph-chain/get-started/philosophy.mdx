# 哲学

LangChain由几个核心理念驱动：
- 大型语言模型(LLMs)是一项伟大而强大的新技术。
- 当你将LLM与外部数据源结合时，LLM甚至会更好。
- LLM将改变未来的应用程序。具体来说，未来的应用将越来越agentic。
- 这一转变还处于早期阶段。
- 虽然构建这些agent应用程序的原型很容易，但构建足够可靠的agent以投入生产仍然非常困难。

如今，开发人员可以选择如何构建agent：使用LangChain实现最大的灵活性和控制，或者使用Deep Agent，它允许类似的灵活性和控件，但附带了有主见的内置规划、文件系统工具、subagent和上下文管理。
两者都是基于LangGraph构建的。

通过LangChain，我们有两个核心重点：
1. 我们希望开发人员能够使用最好的模型进行构建。

    不同的模型提供者提供不同的API，具有不同的模型参数和不同的消息格式。将这些模型输入和输出标准化是一个核心重点，使开发人员能够轻松地更改为最新的最先进模型，避免锁定。

2. 我们希望使使用模型来编排与其他数据和计算交互的更复杂的流更加容易。

    模型不应仅用于文本生成，还应用于编排与其他数据交互的更复杂的流。LangChain使定义LLM可以动态使用的工具变得容易，并有助于解析和访问非结构化数据。
